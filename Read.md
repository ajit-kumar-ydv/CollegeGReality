# 🎓 College Ground Reality (CGR)

> **Honest • Unfiltered • Verified**  
> Empowering students & parents to see past inflated placement statistics, hidden fees, and marketing hype before paying college admission fees.

---

## 🚀 Overview

**College Ground Reality (CGR)** is a student-first initiative built to expose common college marketing traps in India (such as inflated average packages, distorted 100% placement records, hidden campus costs, and international PR stunts). 

This repository contains the complete source code for the landing page, custom pure CSS marquee ticker, Tally.so form integration, and the official **2026 College Reality Checklist PDF**.

---

## ✨ Key Features

- **⚡ High-Performance Landing Page:** Built with lightweight, semantic HTML and Tailwind CSS for instant load times.
- **🔄 Pure CSS Continuous Marquee:** Zero-JavaScript ticker animation for zero layout lag and fast GPU-accelerated performance.
- **📑 Integrated PDF Lead Magnet:** Direct access to `college-guide-2026.pdf` download upon form completion.
- **📱 Fully Responsive Layout:** Pixel-perfect rendering across mobile, tablet, and desktop viewports.
- **🔒 Anonymous Review Collection:** Embedded Tally form integration for verified seniors to share unfiltered campus experiences.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS
- **Animations:** Pure CSS3 (`@keyframes` transform)
- **Deployment:** Vercel
- **Forms & Lead Generation:** Tally.so
- **PDF Lead Asset:** `college-guide-2026.pdf`
